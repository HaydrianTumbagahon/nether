# Nether

Nether is a static editorial blog by HADES about web development, AI in web work, and PC peripherals, including keyboards, mice, and in-ear monitors. It brings together articles, product data, and gear coverage.

## Technology

- Astro with static output
- TypeScript and MDX content collections
- Tailwind CSS v4
- React islands
- GSAP with ScrollTrigger and Lenis
- Pagefind in the build pipeline; site search uses a generated first-party JSON index
