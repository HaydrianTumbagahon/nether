I test AI tools on one bounded task at a time. That makes it easier to see whether I saved time or moved the work into review.

## Start with a defined task

I give the tool a small change with clear inputs, then compare its output with the surrounding code and project conventions.

<Aside>
  I do not count generated lines as progress. I count work that still holds up
  after review.
</Aside>

## Keep the review visible

I note what needed correction, what was already useful, and whether the same task would be faster without the tool.
